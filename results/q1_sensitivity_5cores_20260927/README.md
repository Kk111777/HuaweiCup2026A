# 第一问 V1 基座：5 核 β 灵敏度分析

本目录归档第一问 V1 TaskGrowth 基座在 **5 核**条件下的正式分层样本实验。运行源码为提交 `76055b2ac97cb03122f99d5cd1ada86fcb564f34`；原生完整扫描分别构造固定 β=1、2、3、4，默认自适应策略另行原生运行。固定 β 在 `global` 与 `components` 模式间按官方周期、额外搬运量和模式顺序择优；自适应策略按原生早停规则执行。基座和官方评价代码未修改。

100 张官方图按非 COPY 计算操作数排序并分成四个各 25 张的规模层，用种子 `20260927` 每层抽取 5 张，共 20 张图。同一图的五种方案逐一由独立进程调用官方评价程序复评，因此共有 **100/100 份成功复评**，无失败或缺失。原始运行目录的审计通过 **1008 项产物哈希**；本归档的 300 个最终方案、官方结果及指标文件另在 `archive_manifest.json` 中逐项记录哈希。

## 主要结果

逐例计算 `100 × (T_fixed / T_adaptive − 1)`，其中 `T` 为官方周期数；正值表示固定 β 更慢，然后对 20 张图汇总。

| 固定 β | 平均周期变化 | 中位数 | 更快／持平／更慢 |
|---:|---:|---:|---:|
| 1 | +5.187% | 0.000% | 0／18／2 |
| 2 | +14.523% | +5.321% | 0／5／15 |
| 3 | +17.648% | +5.351% | 1／3／16 |
| 4 | +19.754% | +6.409% | 3／2／15 |

β=1 的平均值主要由 `case_063` 的 +103.536% 拉高；其余 18 张图与自适应持平，另 1 张图变化为 +0.213%。自适应策略在 16/20 张图上达到四个固定 β 中的最短周期；相对四档最短周期的平均差距为 0.729%，最大为 9.638%。这衡量的是本次四档扫描中的早停代价，不是全局最优性差距。

该样本只有一个抽样种子，结论限于这 20 张图及 5 核 V1 基座，不能表述为百例全量或其他核数、V2/V3 的结果。原始批次使用 2 个本机 worker，墙钟用时约 286.2 秒；求解时间的固定 β 与自适应口径不同，不据此比较端到端运行加速。报告使用无图模式生成。

## 归档文件与核验

- `REPORT.md`：程序生成的中文报告。
- `details.csv`、`paired_details.csv`：100 份最终结果和逐例配对变化。
- `summary.csv`、`summary.json`：各 β 的均值、中位数、四分位、任务数、搬运及耗时。
- `selection_manifest.json`：抽样总体、选中图、输入与源码哈希、配置及 Python 版本。本文件将原始运行清单中的本机绝对路径改成可移植的相对路径；`archive_manifest.json` 保留原始清单的 SHA-256。
- `audit.json`、`run_status.json`、`report_manifest.json`：完整性检查、运行状态与报告文件哈希。
- `final_plans_and_official_results.zip`：每个 `case/N5/variant/` 下的最终 `plan.json`、无损压缩的官方完整 `result.json.gz` 和 `metrics.json`，共 300 个文件；不包含原始计算图、候选过程、Trace 和本机日志。
- `archive_manifest.json`：ZIP 本身和 300 个成员的 SHA-256。
- `manifest.sha256`：本目录其余发布文件的 SHA-256。

从本目录运行 `shasum -a 256 -c manifest.sha256` 可核对发布文件。复评时先用 `selection_manifest.json` 中的 SHA-256 核对同版官方输入，将 ZIP 中的 `plan.json` 交给仓库 `official/code/multicore_cut_evaluate_problem_1.py`，并固定使用 `official/data/config.txt`；所得完整结果应与归档中的 `result.json.gz` 相同（输入与方案文件名元数据除外）。原始本地输出另由 `tools/q1_sensitivity.py audit` 核对，以上 1008 项产物哈希均已通过。
