## 已知问题

1. **顺序不一致。** 构造代理按节点接纳序更新，但同一子图的官方执行计算顺序可能不同，
   因而最终方案不能保证实现构造时所优化的顺序。
2. **局部性保护不足。** `component_grouped` 限制候选范围，不保证独立计算分量整体同核；
   逐节点分核可能产生额外跨核通信。
3. **缓存目标与正式目标不一致。** 旧窗口 DP 最小化无换出驻留峰值，可能在无实际 spill 时重排，
   不能据此推导 Makespan 改善。其正式评价保底仍保留，因此并非所有窗口变化都会被接受。
4. **β持平时过早停止。** 1.1沿用严格下降才继续的规则，可能跳过先持平、后改善的参数。

这些属于设计和性能问题，不等于旧版全部输出非法，也不表示每个用例都会退化。
旧版日志、原说明和历史结论按原样保存在ZIP内；其中“当前/默认”等表述只描述历史状态。
当前推荐版本为[Q2 2.0 修复新基座](../../../docs/q2/repair.md)。
