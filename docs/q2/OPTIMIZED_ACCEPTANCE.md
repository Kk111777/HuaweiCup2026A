# Q2 v3 基座优化模型：发布前有限验收与 Q1 对照

试跑日期：2026-09-26。工作分支：`feat/Zysishuiyears/q2-optimized`，基于更新后的 `main@fd0c978`。试跑时尚未提交和推送，没有运行全量或消融。发布时按要求命名为 v3（`Q2-Optimized-3.0`）；本报告四组历史试跑的内部版本为 `Q2-Optimized-1.0`，原始版本字段、数值和哈希均保留。发布命名与隔离缓存扩展后重跑组件和回归测试，不重复大图实验，详情见[版本说明](VERSIONS.md)。

## 1. 结论与边界

默认开启基座保底后的四组结果均通过冻结计划后的独立官方 CLI 复评，**4/4 严格优于本次重新计算的新基座，3/4 优于 Q1v3**。四组当次基座周期均与主分支 Q2 2.0 全量归档一致。`086/N5` 的改善仅 28 周期，仍明显落后 Q1v3，不能宣称优化模型已经取得全量优势。

这些结果来自原始 DAG、单 worker、每组最多两批局部优化；每张图的请求核数共享 600 秒目标、900 秒条件延长和 1200 秒硬上限。本轮每张真实图仅请求表中的一个核数，四组都在 600 秒内结束。多核数共享预算与先轮转检查点由小图和公共框架测试验证。Q1 历史结果的机器、并发和搜索时长不同，本表不是同机同预算的性能对照。

## 4. 首轮退化、修正及仍未解决的差距

首轮无基座保底的两批试跑是 **3 改善、1 退化**，不是“大部分退化”。结果完整保留：

| 组合 | 新基座 | 首轮无保底 | 修正后默认版 |
|---|---:|---:|---:|
| 004/N2 | 198342 | 194802 | 194802 |
| 010/N5 | 25350 | **20563** | 21924 |
| 059/N5 | 150782 | 149450 | 149450 |
| 086/N5 | 62847 | 72016 | **62819** |

`086` 首轮只测到部分独立 β 流，commit 流未推进到 β=3；优化从 β=1 的 73589 出发，无法获得完整新基座的 62847 起点。按用户追加要求，默认流程改为在同一构造器、评价服务和方案池内先完成基座候选，再开始两批局部优化，最后以精确成绩择优。没有串接两个独立求解器，也没有读入已归档基座计划。发布前若估计改进不被官方确认，则使用精确最好方案；独立复评仍不反馈改选。

保底保证的是**不退化于完整完成的当次基座**，不是所有案例必然严格改善。`baseline_guard.complete=false` 表示基座因资源或预算未完成，不能宣称完整基座保证。本轮四组该字段均为 true。

`010` 的 20563 没有被静默合入新版本结果。加入完整基座后，两批搜索的父状态和轨迹改变，得到 21924。首轮与修正版是两次不同配置的算法运行，不能利用离线成绩挑选历史方案再冒充一次运行结果。后续可在共同预算内研究不同父状态的搜索名额，保留强分支的探索机会，但本轮未扩展两批上限或添加特定用例规则。

`086` 有 5274 个计算操作，计算依赖只有一个弱连通分量。最终方案各核心最大的 M/V 工作量分别为 13074、13240、17028、20478、15924，远低于 62819 总周期；它并非单纯由计算负载不均衡主导。当前映射的基础 DDR 工作为 **43270** 周期，已经超过 Q1v3 的 **37003**，而加入真实执行顺序约束后的路径下界为 **58190**。因此只在当前映射上微调顺序不可能追上 Q1v3。

本轮 `086` 已细化的家族最好值为重排 68355、重新分核 77090、反馈迁移 62819；第二批没有进一步降低时间。数据支持下一步重点改进大连通图的迁移区域与通信结构、扩大不同映射的父方案探索，而不是声称通过加大排序窗口就能消除差距。未使用 Q1v3 方案参与当前搜索。

## 5. 组件与回归

Python 3.12.14；完整测试共 **280 项，278 通过，2 跳过**，耗时 42.069 秒。

- 40 张随机小图 × 2/3/5 核，共 120 份方案；4478 个操作的开始、结束时刻逐项与未修改官方程序一致。
- 最小图 6 周期；缓存控制例 3736 → 2302，spill 80000 → 0。
- `059/N5` 两个固定误筛候选：粗层均 150736，细层与独立官方分别为 156177（spill 81920）和 157856（spill 0），复现参考现象。
- 通信增量与完整重算一致；稀疏 ready 更新与逐次扫描一致；父状态隔离、迁核、试放回滚、多 sgid 块、跨核路径和容量窗口回归通过。
- 缓存命中后的保真拒绝、执行等价只正式评价一次、环境失效与淘汰、配额、校准回退、β 待反馈、非法间隔、批次中断保留及发布前退化回退通过。
- 小图真实子进程公共入口、先轮转全部核数检查点、完整实例恢复、篡改/跨版本拒绝、未知合法性不可入池、复评失败不发布标记通过。
- Q1、公共框架、Q2 1.1 对照和修复基座回归通过。官方代码未改动。

两项跳过原因：缺少冻结的重构前差分归档；原附件压缩包不在当前工作树内的预期位置。后者另从用户原项目的真实附件读取，独立逐字节核对 **10/10 官方 Python 文件一致**。

四组试跑后仅将公共请求文件中的基座策略标签改为 `backend_owned`，避免与 Q2 的保底模式相矛盾；Q1 标签不变，算法与评价逻辑未变。对应 Q2/公共运行测试追加重跑 **26/26 通过**。试跑源码指纹与交付指纹分别保存在清单中，不伪称为同一文件快照。编译检查与 `git diff --check` 通过。
