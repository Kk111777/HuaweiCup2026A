## 另一台机器运行

将原始 DAG 放到 `official/data` 或替换下述路径，使用 Python 3.12：

```powershell
# 只检查086/N5入口
python scripts/validate_q2_repair.py --data-dir official/data --output-root outputs/q2_v2_check

# 全量100×4；本轮未执行，无需先跑消融
python scripts/validate_q2_repair.py --suite full --data-dir official/data --output-root outputs/q2_v2_full --workers 1 --resume
```

默认 adaptive β 已开启，规则为持平继续、严格增时才停止，默认上限4。
每组合600秒预算，初始预留60秒复核。`--resume` 只复用身份一致且文件完好的已验证组合；
不接续任意中断指令，不混用1.1或早期源码的结果。消融配置和入口已准备，待需要研究组件归因时再运行。
