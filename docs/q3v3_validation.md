固定Q2周期T2/新折衷Q3周期T3的逐例算术均值为1.159037倍，18快/2平/0慢。Q2搜索预算不同，不能解释为等预算算法对决。DDR/spill改善主要来自容量与顺序变化，不能全部归因于L2窗口；继承起点与新增搜索的收益在本地报告中分开记录。

有效批次墙钟173.01秒，起点官方预备重放另计53.32秒；实测20个独立主机worker及峰值20组并行。每组搜索上限120秒、64次评价，准备和最终重放单独计时。模拟NPU核数与主机进程数不同。

原实验81项Q3v3测试通过。发布在最新main的独立工作区进行：`python -m unittest discover -s tests -p "test_q3*.py" -v` 运行102项测试，101通过、1跳过；同时覆盖新Q3v3和已发布Q3。跳过的是已有Q3的一项正式输入依赖测试：隔离发布工作区未放入原始case数据；81项Q3v3测试全部通过。测试墙钟31.959秒。

发布源码与实验相比，只新增克隆仓库下的Q1纯图源路径发现（默认可使用本仓库 `src/`），并将一项语义测试改为调用官方Q1评估器，消除对历史私有函数签名的依赖。完整方案主路径和搜索算法未改变，没有把原成绩冒充为新目录下重新搜索的成绩。

## 边界

- 本轮只覆盖N=2～5，尚未完成Q3v3的N=1实测或百例验收。已有完整单核JSON时可搜索；自动单核起点未接入。已有 `src/q3/` 的其他实验属于另一个实现。
- 加权目标是工程偏好，官方评估规则未修改。1%上限相对已发现最快可行解，不相对未知全局最优。
- FIFO重读与COPY字节有重合，不能再次相加当作总流量；命中率按合并字节计算，不按逐例百分比直接平均。
- 20路限时搜索受主机竞争影响，重新搜索可能探索不同数量的候选。原始可复核产物保存在本地 `outputs/q3v3_q1q2_memory_traffic20_r2_20260927/`。
